# Newsletter de Incendios y Prevención

Una plataforma web comunitaria para centralizar información sobre feugos cercanos y prevención de incendios.

Este proyecto nace con el objetivo de ser un punto de encuentro para los vecinos del alto palancia y castellón, donde puedan informarse de manera veraz sobre prevención y sobre la situación de los incendios en la zona y realizar consultas directas a las autoridades competentes. Cualquiera puede ver la lista de preguntas  y sus respuestas siempre que el usuario o el administrdor las hayan marcado como visibles para los demás. También se está implementando la opción de crear un foro donde se pueda debatir.

#ACCESO
https://infoincendios.alwaysdata.net/

De momento un usuario puede leer las noticias que se suben, escribir preguntas, recibir respuestas y leer las preguntas y respuestas que escriben los demás usuarios.
Para respondeer a las preguntas hay que tener un acceso de administrador.
