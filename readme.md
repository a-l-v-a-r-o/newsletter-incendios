# Newsletter de Incendios Locales

Una plataforma web comunitaria para centralizar información sobre prevención e incendios cercanos.

Este proyecto nace con el objetivo de ser un punto de encuentro para los vecinos del alto palancia y castellón, donde puedan informarse de manera veraz sobre prevención y sobre la situación de los incendios en la zona y realizar consultas directas a las autoridades competentes. También se está implementando la opción de crear un foro donde se pueda debatir.
